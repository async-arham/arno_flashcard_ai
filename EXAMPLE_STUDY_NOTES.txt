An algorithm is a sequence of steps for solving a problem.
A variable stores a value that a program can use.
A function is a reusable block of instructions.
A loop repeats instructions while a condition holds.
An array stores multiple values in an ordered collection.
A stack uses the last-in, first-out principle.
A queue uses the first-in, first-out principle.
A binary tree is a tree in which each node has at most two children.
Depth-first search explores a branch before backtracking.
Breadth-first search explores nodes level by level.
